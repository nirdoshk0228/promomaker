Answer key format

An answer key lists the promos a human editor would cut, so PromoFinder's picks can be checked against them. Times are episode timecodes as MM:SS.ss (or plain seconds).

{
  "promos": [
    { "promo_id": "P01", "type": "single",
      "segments": [ { "episode": 1, "start": "01:00.40", "end": "01:33.00" } ],
      "why": "Opens on the slap, ends on the frozen face" },
    { "promo_id": "P07", "type": "stitched",
      "segments": [ { "episode": 1, "start": "01:00.40", "end": "01:06.40" },
                    { "episode": 6, "start": "00:36.10", "end": "00:57.40" } ] }
  ],
  "traps": [
    { "episode": 5, "start": "00:44.10", "end": "00:47.20",
      "reason": "Loud line, but needs earlier context" }
  ]
}

traps is optional: moments that look dramatic but should not open or close a promo. The check reports how often PromoFinder falls for them.
